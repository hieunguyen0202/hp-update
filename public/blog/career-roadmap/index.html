My Career Roadmap

Lộ trình 24 tháng tới Senior DevOps Engineer — bắt đầu từ vị thế Kubestronaut, chinh phục AWS, rồi mở rộng sang AI for DevOps và Security, song song Leadership & Business.

Start (ước tính): Sep 2026 Target: Aug 2028 · Senior DevOps Baseline: Kubestronaut ✓
I already know

Kubestronaut — Kubernetes mastery unlocked

KCNA · CKA · CKAD · KCSA · CKS đã hoàn thành. Không học lại Kubernetes fundamentals — dùng K8s như nền tảng để nhảy sang cloud AWS, platform, AIOps & security.

Containers ✓ Orchestration ✓ Cluster Admin ✓ App Deploy ✓ K8s Security ✓

How long will Phase 0 take?

Sprint ngắn hạn (~120 giờ học + lab). Chọn số giờ/ngày — giống KodeKloud Kubestronaut path. Lộ trình tổng vẫn cố định 24 tháng (kỹ thuật + leadership + business chạy song song).

I can spend
hours / day

Phase 0 (AWS foundation + project + certs) ≈ ~10–12 weeks at a sustainable pace

24-month overview

Ba trụ chạy song song: Tech Leadership Business — Tech chiếm ~60%, Leadership ~25%, Business ~15%.

Q1 Sep–Nov 2026 AWS + EKS + Terraform sprint
Q2 Dec 2026–Feb 2027 AWS certs + Platform depth
Q3 Mar–May 2027 GitOps · Observability · Cost
Q4 Jun–Aug 2027 Security depth · Mid→Senior bridge
Q5 Sep–Nov 2027 AI for DevOps / AIOps
Q6 Dec 2027–Feb 2028 DevSecOps · Cloud security
Q7 Mar–May 2028 Leadership · Architecture
Q8 Jun–Aug 2028 Senior packaging · Interview
